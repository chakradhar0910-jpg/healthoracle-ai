# Security Policy

## Supported Versions

We actively support the latest release of HealthOracle AI:

| Version | Supported          |
| ------- | ------------------ |
| 4.0.x   | :white_check_mark: |
| < 4.0.0 | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability, please do not report it publicly. Instead, contact us via email at `chakradhar0910@gmail.com`.

We will investigate the issue and aim to respond within 48 hours to coordinate a responsible disclosure and patch.
